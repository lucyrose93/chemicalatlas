# Chemical Atlas: Visual + Conceptual Patterns Report

## Overview

This report synthesizes core visual motifs and conceptual models drawn from 20 hand-drawn wireframes and sketches for the *Chemical Atlas*. These patterns offer a foundation for translating research themes—chemical interconnections, toxic geographies, embodied impacts—into interactive, visual, and navigational forms for the digital platform.

---

## 1. Recurring Visual Forms

### 🧬 **Network Diagrams**
- **Nodes + Lines**: Circular or molecular nodes connected via radial or web-like lines.
- **Interpretation**: Suggests relationships between chemicals, stories, locations, people.
- **Common Uses**: Index views, case study maps, home page visualisers.

### 🪐 **Globes + Circular Maps**
- **Earth/Planet Shapes**: Multiple sketches feature Earth-like globes or amorphous maps with embedded points.
- **Interpretation**: Signals scale (planetary), universal relevance, or environmental reach.
- **Common Uses**: Landing page visuals, thematic overviews.

### 🧭 **Contours + Topographies**
- **Layered Contour Lines**: Often used to evoke depth, terrain, or non-linear navigation.
- **Interpretation**: Represents interconnected issues or multi-scalar complexity (e.g. bodily ↔ planetary).
- **Common Uses**: Issue overviews, filters, relational mapping.

### 🧪 **Grids + Tables**
- **Chemical Table Grids**: Referencing periodic table formats to structure chemicals or themes.
- **Interpretation**: Evokes scientific taxonomies while inviting reclassification.
- **Common Uses**: Navigation by chemical, story archive, or template entry.

---

## 2. Conceptual Frameworks

### 🔄 **Interconnectedness**
- **Chemicals ↔ Bodies ↔ Geographies**: Diagrams frequently represent hybrids (human–nonhuman, industrial–biological).
- **Implication**: Design must support jumping between levels: molecule → body → territory → policy.

### 🧍‍♀️ **Embodiment & Testimony**
- **Figures + Personal Experience**: People are drawn as carriers of chemical exposure or as narrative anchors.
- **Design Insight**: Include testimonial story formats and emphasize voice/subjectivity in data.

### 🌐 **Mapping the Invisible**
- **Data Layers**: Invisible phenomena (toxicity, exposure, molecular processes) visualized using dots, densities, glows.
- **Implication**: Interface should surface unseen impacts (e.g. hormone disruption, long latency effects).

### 🧭 **Non-linear Navigation**
- **Fluid Maps & Multinodal Paths**: Shapes and layouts reject strict hierarchy or chronology.
- **Design Insight**: Enable browsing by chemical, place, concern, or story simultaneously.

---

## 3. Interface Suggestions

| Element           | Suggested Format                   | Rationale                                        |
|------------------|------------------------------------|--------------------------------------------------|
| Home visualizer  | 3D molecular network (draggable)   | Central metaphor; flexible entry point           |
| Story index      | Contour map or dynamic web         | Emphasizes connections over fixed lists          |
| About/methods    | Grid ↔ network toggle               | Transparency of approach and multiple readings   |
| Story detail     | Layered visual-text layout          | Longform + relational graphics                   |
| Filter/Explore   | Sidebar with map, chemical, themes | Navigable by user concern or curiosity           |

---

## 4. Design Principles

- **Relational, not reductive**: Let forms suggest relationships, not categories.
- **Aesthetic coherence**: Line-based, gestural, and organic visuals echo conceptual themes.
- **Multi-scalar**: Enable zooming in/out—from molecular detail to global impact.
- **Participatory**: Design with space for user-contributed stories, testimonies, or data.


*Compiled from 20 sketches by workshop participants (June 2025).*
